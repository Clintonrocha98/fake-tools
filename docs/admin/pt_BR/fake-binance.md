# Fake Binance

A seção Fake Binance é o **controle remoto de cenários** da fake Binance. O happy path (crédito fiat, fill spot, conclusão de withdraw) avança sozinho — nenhuma dessas páginas precisa de clique para funcionar. Elas existem para os cenários de falha que a aplicação consumidora precisa exercitar sob comando: forçar um status, atrasar um brcode, congelar uma ordem, ou ligar um switch global que faz todo endpoint se comportar mal.
